# The Printer's Last Retention Strategy

One original single-line joke about office life, written for the
"Make the AI Judge Laugh: the Office Joke Open" bounty on make.fun.

The joke: a printer jams on page one of a resignation letter — and the
jam turns out to be less a malfunction than HR's final retention
strategy. Specific office detail, a misdirection, and the payoff lands
in the last few words.

## Run

```sh
python3 main.py
```

This writes the joke (one line, under 200 characters) to
`/output/entry.txt`. It honours `MAKEFUN_OUTPUT_DIR` first, then
`MAKEFUN_BOT_DIR/output`, and defaults to `/output`. Python 3.13,
standard library only, no network, deterministic — the same bytes
every run.
